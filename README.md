# WorkBuddy 小白上手指南

> 写给第一次用 AI 工具的人：不装环境、不写代码，用大白话说需求，让它把活干完并把文件交给你。

本书内容依据 WorkBuddy 官方文档整理，并把新手最容易踩的坑标了出来。全文约 10 分钟读完，照着做一遍就能上手。

## 1. 它到底能干什么

一句话：**你描述要什么，它自己拆步骤、找方法、动手做，最后把能直接用的文件交给你。**

和普通聊天机器人的区别在于"交付物"：

| 普通 AI 对话 | WorkBuddy |
| --- | --- |
| 给你一段文字建议 | 给你一个 Word / Excel / PPT 文件 |
| 告诉你"可以这样整理照片" | 直接把照片按日期分好文件夹 |
| 给你一段代码片段 | 把项目跑起来，网站能打开 |
| 只能一问一答 | 能连续追问、边做边改 |

适合交给它的活，通常是这几类：

- **写**：报告、方案、周报、公文、合同初稿、公众号推文
- **算**：Excel 清洗、多表汇总、数据透视、图表
- **做**：PPT、网页、小程序、简单的内部工具
- **理**：批量重命名、按规则归档、从一堆文件里提取信息
- **查**：查资料、做调研、对比多个来源后给结论

不太适合的：需要当面沟通的事、需要现场操作的实体工作、以及你自己也说不清要什么的事（先想清楚目标再交给它）。

## 2. 五分钟做出第一个结果

### 第 1 步：打开一个新任务

打开 WorkBuddy，点左上角新建任务，在输入框里用一句话说清楚你要什么。

```
把这份销售数据做成一份带图表的分析报告
```

### 第 2 步：把材料给它

两种方式，任选：

- 点输入框的上传按钮，或者把文件直接拖进输入框
- 复制截图后按 `Ctrl + V` 直接粘贴

支持 PDF、Word、Excel、CSV、PPT、图片、压缩包和常见代码文件。

### 第 3 步：按下发送，然后看着它干

它会把过程展示在对话区：正在分析数据、正在生成图表、正在写文档。你不用盯着，去倒杯水也行。

### 第 4 步：去右边拿结果

结果不会只在聊天里，它躺在右侧结果区的**产物**页签里。点开就能预览、另存为、分享出去。

> 如果你只得到一个文件路径，说明它把文件写在了工作空间里——右侧「工作空间文件」能看到完整目录。

## 3. 认识界面：四个区域

```
┌──────────────────────────────────────────────┐
│  工具栏：关于、编辑、窗口等常用操作              │
├────────────┬──────────────────┬──────────────┤
│  侧边栏     │   对话区          │   结果区      │
│  任务列表   │   你说话 + 它干活  │   产物/预览    │
│  按文件夹分组│   执行过程可见     │   文件/变更    │
└────────────┴──────────────────┴──────────────┘
```

- **侧边栏**：所有任务都在这里，按文件夹分组，可以搜索。任务不会丢，随时点回来接着聊。
- **对话区**：核心区。你提要求，它汇报进度，你继续追问。
- **结果区**：产出物集中地。四个页签——产物、网页、工作空间文件、变更。

记不住没关系，只用记住一句话：**左边是历史，中间是聊天，右边是成果。**

## 4. 三种模式，别选错

发起任务前可以选模式，这决定了它"先想还是先做"：

| 模式 | 它怎么干 | 什么时候选 |
| --- | --- | --- |
| **Agent（执行）** | 直接动手，边做边说 | 目标清楚、要的就是结果。日常九成任务用这个 |
| **Plan（规划）** | 先给一份步骤方案，等你确认后再动手 | 任务复杂、影响面大、你还没想清楚怎么做 |
| **Ask（问答）** | 只回答、只分析，不动你的文件 | 只想问清楚概念、看看方案，别碰我的东西 |

新手建议：**默认用 Agent**。遇到下面两种情况再换：

- 怕它乱改文件 → 用 Ask 先问明白
- 活儿太大（比如重构整个项目、批量改几百个文件）→ 用 Plan 先审方案

## 5. 会说话就会用：把需求说清楚的公式

它不是"猜你心思"的工具，说得越具体，返工越少。一个好用的公式：

> **目标 + 输入 + 输出格式 + 约束**

### 反面例子

```
帮我整理一下这个表格
```

它不知道你要整理什么：去重？补空值？排序？还是要做汇总？

### 正面例子

```
把附件里的销售明细表整理成一份月度汇总表。
输入：2026 年 1-9 月的订单明细，含日期、产品、金额、销售员四列。
输出：Excel 文件，按月份和产品两个维度汇总销售额，附一张折线图。
约束：金额保留两位小数，空值按 0 处理，缺失日期的行单独列出来。
```

区别就在四个要素齐不齐。再看几个可以直接抄的例子：

| 场景 | 可以这么说 |
| --- | --- |
| 做 PPT | 根据这份会议纪要生成 12 页 PPT，面向管理层，风格简洁，首页要有标题和日期 |
| 读文档 | 读这份 30 页合同，列出对我方不利的 5 个条款，逐条说明风险，输出表格 |
| 处理表格 | 把表里重复的手机号去重，保留最新的那条，输出新文件不要覆盖原表 |
| 做网页 | 做一个产品介绍单页，深色科技风，手机端也要好看，能直接打开预览 |
| 调研 | 查 2026 年国内 AI 办公工具的市场格局，给 3 个主要玩家对比，注明信息来源 |

### 三个提高成功率的小技巧

1. **先给样例**：如果有"就想要这种风格"的参考文件，一起传给它。
2. **分步提要求**：复杂的活别一句话说完，先出框架，满意了再让它填内容。
3. **告诉它不要什么**：比如"不要用表格排版"、"不要写营销腔"、"数字不要编"。

## 6. 把资料喂给它

它看不到你脑子里的背景，得你给。四种常见方式：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 上传文件 | 点上传按钮，或把文件拖进输入框 | 有现成材料 |
| 粘贴截图 | `Ctrl + V` 直接粘 | 报错信息、设计稿、网页效果 |
| `@` 引用 | 输入 `@` 选文件或规则 | 引用工作空间里的文件 |
| 口述 | 点输入框的语音按钮 | 不方便打字时 |

如果原始资料是录音，可以直接上传音频，让它转成文字再处理。

## 7. 结果去哪儿了

右侧结果区有四个页签，各管一摊：

| 页签 | 装什么 | 什么时候看 |
| --- | --- | --- |
| **产物** | 生成的最终文件（Word/Excel/PPT/PDF） | 拿结果、分享、上传云端 |
| **网页** | 生成的网页、原型、Web 应用 | 看页面效果是否对 |
| **工作空间文件** | 当前目录下的所有文件 | 检查文件写到哪了 |
| **变更** | 这次任务改了哪些文件 | 动手改代码/配置后先审一遍 |

每个产物卡片右边有个「⋯」，里面能：

- **打开文件夹**：定位到本地目录
- **在默认应用打开**：用 Word/Excel 打开
- **复制路径**：拿到路径去别处用
- **另存为**：存到你想存的地方
- **上传到云端**：存进资料库、腾讯文档、ima 知识库等

产物预览页右上角还能**分享**：生成链接发给别人，或者直接发到微信 / 企业微信。

> 注意：「变更」页签是给你复核用的。涉及改文件的任务，先在这里扫一眼，确认没动到不该动的东西。

## 8. 不满意怎么改

**不要重新开一个任务**。在同一个对话里接着说，它记得前面所有上下文。三种说法最好用：

| 你的目的 | 直接这么说 |
| --- | --- |
| 加东西 | "再加一个饼图"、"每章补一个案例" |
| 改已有结果 | "表格按销售额降序排"、"语气再正式一点" |
| 往下推进 | "把这份报告导出成 PDF"、"再分析一下环比" |

还有两个少有人知道的用法：

- **引用着改**：选中它回复里的某段文字，点「添加到对话」，然后在旁边写"这段重写，要更简短"。它就知道你指的是哪一段。
- **边跑边补**：它正在干活时你也能发消息，消息会进队列，等当前这轮做完自动接着处理。不会打断，也不会丢。

任务卡住了？直接点停止，改完要求重新发，比干等强。

## 9. 进阶：技能、专家、连接器、资料库

用顺手之后，这四个东西能把效率再拉一截。名词有点唬人，其实很好理解：

| 概念 | 打个比方 | 解决什么问题 |
| --- | --- | --- |
| **技能（Skill）** | 一套固定动作的操作手册 | 让它在某类活上按专业流程做，比如生成公司格式的 PPT |
| **专家** | 请一位领域顾问坐你旁边 | 需要行业判断时用，比如投资分析、法务审查、招聘 |
| **连接器（Connector）** | 给它开一扇通往别的系统的门 | 让它能读你的邮箱、文档、仓库、项目管理系统 |
| **资料库** | 你的私人素材库 | 把常用资料存起来，以后任务里直接引用 |

拿不准要不要装：**先想清楚"我是不是缺一份数据/一套方法"**。

- 缺数据（在我邮箱里、在我仓库里）→ 装连接器
- 缺方法（不知道这类活该怎么干）→ 用专家或技能
- 缺素材（每次都重复上传同一批文件）→ 用资料库

## 10. 隐私与安全

这部分值得花一分钟看：

- 文件处理默认在**本地**完成，原始数据不上传云端
- 它只能访问你**主动授权**的文件夹，系统敏感目录会被自动拦截
- 高危操作（删除、覆盖、批量修改）会**二次确认**
- 所有产出物、变更记录都留痕，随时可以回看

给你的建议：第一次用某个涉及文件的操作时，用 Plan 模式或 Ask 模式先看它打算怎么动，确认无误再放行。

## 11. 常见问题

**Q：它做的文件在哪儿？我关掉软件还在吗？**
在。文件写在本地工作空间目录里，右侧「工作空间文件」能看到路径。关掉软件不影响。

**Q：任务太多找不到了？**
左侧边栏点搜索，或者按文件夹分组看。每个任务都能点回去接着聊。

**Q：同一个问题问第二遍，它为什么答得不一样？**
每次任务都是独立上下文。想要连贯，就在同一个任务里追问，别新开。

**Q：它能上网查资料吗？**
可以，会给出信息来源。但涉及具体数字、政策、价格这类会变的信息，建议自己再核一遍。

**Q：为什么它老是问我一堆问题？**
说明需求还不够具体。把第 5 节那四个要素补齐，它能少问一半。

**Q：做 PPT / Excel 会不会格式很丑？**
默认模板够用但不出彩。想要好看，传一份你喜欢的样例文件让它照着做。

**Q：会不会把我的文件改坏？**
涉及修改的任务，改完在「变更」页签能看到每一处改动。重要文件建议先备份，或者让它"输出到新文件，不要覆盖原文件"。

## 12. 一页速查表

```
开始一个任务
  选模式（默认 Agent）→ 说清 目标 / 输入 / 输出 / 约束 → 传材料 → 发送

材料怎么给
  拖文件 · Ctrl+V 粘截图 · @ 引用 · 语音口述

结果在哪看
  右侧结果区：产物 · 网页 · 工作空间文件 · 变更

不满意
  别新开任务，在同一对话里说："再加…" / "改成…" / "接着做…"

拿不准
  复杂任务先用 Plan 审方案；只问不动手用 Ask
```
