# 提示词模板库

直接复制，把方括号里的内容换成你的实际情况。模板不是咒语，重点是四要素齐全：**目标 + 输入 + 输出 + 约束**。

---

## 一、文档类

### 1. 会议纪要 → 结构化纪要

```
把附件里的会议录音转写稿整理成一份会议纪要。
输入：转写稿（含口语重复和错别字）。
输出：Markdown 格式，包含【会议信息】【结论】【待办事项】三部分，待办要带负责人和时间。
约束：待办事项只保留明确分配到人的，模糊表述不要编造负责人。
```

### 2. 长文档提炼

```
读这份 [合同/报告/论文]，输出一份 500 字以内的摘要，外加一个"关键条款/结论"表格。
约束：所有引用必须来自原文，不要加入你自己的判断；数字要带原文页码。
```

### 3. 对外材料改写

```
把这份内部周报改写成给客户看的项目进展说明。
约束：去掉内部代号和人名，语气专业但不生硬，长度控制在 800 字内，不要出现"我们加班赶"这类表述。
```

## 二、表格类

### 1. 多表汇总

```
把这个文件夹里 [12] 个月的销售明细表合并成一张总表。
输出：新的 Excel 文件，包含原始明细页和汇总页。
约束：
- 不要改动原始文件
- 表头不一致时以第一张表为准，并在汇总页注明差异
- 金额列统一保留两位小数
- 重复订单号只保留最新一条
```

### 2. 清洗与去重

```
清洗这份客户名单：
1. 手机号去重，保留最近更新的那条
2. 补齐缺失的省份（可从地址列推断，推断不出的标记为"未知"）
3. 统一公司名称的全角半角
输出：清洗后的新文件 + 一份清洗说明（改了多少行、为什么改）。
```

### 3. 做分析

```
基于这份销售数据做一份分析，回答三个问题：
1. 哪三个产品贡献了 80% 的销售额
2. 环比增长最快的区域是哪个，原因可能是什么
3. 有没有异常值需要人工核实
输出：Excel 里带数据透视和 2 张图表，另附一页文字结论。
```

## 三、PPT 类

```
根据附件里的 [方案文档] 做一份 PPT。
输入：文档约 [5000] 字。
输出：[15] 页左右，16:9，风格 [简洁商务/科技深色/活泼]。
结构：封面 → 背景与目标 → 方案要点（3-4 页）→ 实施计划 → 预期收益 → 结尾页。
约束：
- 每页正文不超过 5 条要点，不要大段抄原文
- 图表优先用图形化表达，不要堆表格
- 首页带标题、副标题、汇报人和日期
```

## 四、网页 / 小工具类

```
做一个 [产品介绍] 单页网站。
要求：
- 深色系，科技感，主色调 [蓝紫渐变]
- 手机端和电脑端都要能正常显示
- 包含：首屏大标题+一句话介绍、功能三栏、客户评价、底部联系表单
- 生成的页面要能直接在预览里打开看效果
约束：不要用需要联网加载的外部字体和图标库。
```

---

## 五、调研类

```
调研 [2026 年国内 AI 办公工具市场]。
输出：一份 1500 字左右的报告，包含市场格局、3 个主要玩家对比表、趋势判断。
约束：
- 每个关键数据都要注明来源链接和时间
- 区分"厂商宣称"和"第三方数据"
- 找不到可靠数据的地方直接写"暂无公开数据"，不要估算
```

## 六、文件整理类

```
整理 [D:\照片] 文件夹：
1. 按拍摄日期（读 EXIF）分到 年/月 子文件夹
2. 重命名为 [日期_序号] 格式
3. 重复文件（内容相同）只保留一份，列一份重复清单给我
约束：
- 先输出一份"将要执行的操作清单"等我确认，不要直接动手
- 不要删除任何文件，重复的移到 [D:\照片\重复] 文件夹
```

> 最后这条是重点：**批量操作类任务，永远先要清单再动手。**

## 通用句式补充

想让它做得更好，可以在这几个地方加一句：

| 想要的效果 | 加这句话 |
| --- | --- |
| 不要瞎编 | "不确定的地方标注'待核实'，不要编造数据" |
| 控制篇幅 | "全文不超过 [800] 字" |
| 统一风格 | "参考附件里的样例，保持相同语气和结构" |
| 保留原件 | "输出到新文件，不要覆盖原文件" |
| 想先看方案 | "先给方案，我确认后再执行" |
| 分步交付 | "先出大纲，我确认后再展开写" |
